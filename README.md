# C 백지 연습장

프로그래밍 및 실습2 (C언어, 1~9장) 시험 대비 공부 사이트입니다.

**사이트 주소: https://xxxodms88.github.io/-/**

- **이론 정리 / 코드 정리**: 장별 핵심 개념과 문법 패턴, 모든 예제 코드
- **함수 퀴즈 (44문제)**: main이 주어지고 함수를 직접 작성, 실제로 실행해서 채점 (작년 기출 포함)
- **개념 빈칸 / 코드 빈칸**: 빈칸과 2~3줄 통째 빈칸, 풀이가 달라도 실행 결과가 같으면 정답
- **직접 코딩**: 사용할 이름만 보고 처음부터 작성, 실행 결과로 채점
- **출력 예측**: 코드를 보고 실행 결과 맞히기

진도와 작성 중인 코드는 각자 브라우저에만 저장됩니다.

## 구성

- `index.html`: 사이트 전체 (편집기는 CodeMirror 5를 cdnjs에서 불러옴)
- `picoc-worker.js`: 브라우저 안에서 C 코드를 실행하는 인터프리터. [picoc](https://gitlab.com/zsaleeba/picoc)(BSD)를 WebAssembly로 컴파일한 [picoc-js](https://www.npmjs.com/package/picoc-js) 1.0.12를 Web Worker용으로 고친 것
- `.nojekyll`: GitHub Pages가 파일을 그대로 배포하도록 함

코드 실행은 웹 주소로 열었을 때만 동작합니다. 파일을 직접 열면 실행만 빠지고 나머지는 동작합니다.
