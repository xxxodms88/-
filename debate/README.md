# 토론 반박 보조 (긍정측 · 토론자 2)

논제 "인간은 인공지능을 통제할 수 있다"에서 긍정측 **반박 · 교차조사 답변 · 보충질의 1회**를 맡은 사람을 위한 실시간 보조 도구입니다.

## 여는 법

1. 이 `debate` 폴더를 통째로 내려받아 `index.html`을 **Chrome이나 Edge**로 엽니다. (설치·빌드 필요 없음)
2. `📚 자료·설정` 탭에서 Anthropic API 키를 넣습니다 (console.anthropic.com에서 발급). 키는 그 브라우저에만 저장됩니다.
3. 토론 시작 직전에 **연결 테스트 + 예열**을 한 번 누릅니다. 팀 자료가 캐시에 올라가서 첫 응답이 빨라집니다.

키가 없거나 인터넷이 끊겨도 **즉석 조립, 준비된 답, 준비된 보충질의**는 그대로 됩니다.

## 실전 순서

| 토론 순서 | 할 일 | 탭 |
|---|---|---|
| 부정측 입론 (2:30) | 🎤 받아쓰기 켜기 (Alt+M). 감지된 카드 확인. 내 보충질의 1회는 여기나 부정측 반박 중에 | ⚡ 반박 / 🎯 보충질의 |
| 긍정측 교차조사 (2:00) | 상대가 인정한 것 체크 → **Ctrl+Enter** 로 AI 반박 생성 (안 되면 **Alt+A** 즉석 조립) | ⚡ 반박 |
| **내 반박 (2:00)** | **Alt+P** 발표 모드 → Space로 스톱워치. K로 키워드만 보기 | 발표 모드 |
| 부정측 교차조사 (2:00) | 질문 입력 → 준비된 답이 즉시 뜸. Ctrl+Enter로 AI 답변 (즉답 먼저) | 🛡 답변 |

## 단축키

| 키 | 기능 |
|---|---|
| Ctrl+Enter | 지금 탭의 AI 생성 (반박 / 답변 / 보충질의 / 모의 답변 제출) |
| Ctrl+Shift+Enter | 저장된 결과 무시하고 반박 새로 생성 |
| Alt+A | 즉석 조립 (AI 없이 0초) |
| Alt+M | 받아쓰기 켜기/끄기 |
| Alt+P | 발표 모드 (Space 시작/정지, R 리셋, K 원고↔키워드, +/− 글자, Esc 닫기) |
| F2 / Alt+S | 스톱워치 시작/정지, Alt+R 리셋 |
| Alt+1~6 | 탭 이동 |
| Esc | AI 생성 중지 + 받아쓰기 중지 |

## 기능

- **⚡ 반박**: 상대 입론에서 논거를 키워드로 바로 감지 (14개 예상 논거 카드). 체크한 카드로 2분 원고를 즉석 조립하거나, AI가 핵심 3줄 → 원고 → 키워드 → 추가 카드 → 논리 오류 → 예상 질문 순서로 스트리밍. 원고 분량은 내 말하기 속도에 맞춰짐. 원고는 직접 고칠 수 있음.
- **⏱ 내 속도 보정**: 원고를 스톱워치로 재면서 읽고 정지한 뒤 누르면, 내 말하기 속도(자/분)를 저장해서 다음 원고 분량이 정확해짐.
- **🛡 답변**: 예상 질문 16개와 답을 즉시 검색. AI는 즉답(예/아니오 먼저) → 이어서 할 말 → 함정 → 역공 순서. 교차조사와 보충질의(30초) 모드.
- **🎯 보충질의**: 규칙 안내, 팀 사용 횟수 카운터, 상대 발언에 맞춰 정렬되는 준비된 질의 (★는 최종발언과 연결되는 질문), AI 추천 질의.
- **🧪 연습**: AI가 부정측 입론 작성 → 반박 연습, AI가 부정측 토론자 1로 교차조사 → 내 답변 채점, 반박 원고 피드백.
- **📚 자료·설정**: 팀 입론·교차조사·최종발언 (AI가 여기에 맞춰 반박을 씀), 근거 자료, 내 카드 추가.
- **🗂 기록**: 생성한 결과를 모두 저장하고 `.md`로 내보내기.

## 주의

- AI는 숫자·날짜·인용을 `근거 자료` 목록과 팀 자료에서만 쓰도록 제한되어 있습니다. **⚠ 최신 확인** 표시가 있는 근거는 토론 전에 한 번 더 확인하세요.
- 받아쓰기(Web Speech API)는 Chrome·Edge에서 동작하며, 음성은 브라우저 회사의 음성 인식 서버로 전송됩니다.
- 근거·카드·예상 질문은 `data.js`에서 고칠 수 있습니다.

## 파일

- `index.html`: 화면
- `app.js`: 동작
- `data.js`: 팀 자료, 근거, 논거 카드, 예상 질문, 보충질의 후보
- `vendor/anthropic-sdk.js`: Anthropic TypeScript SDK 1.8.0 브라우저 번들 (Apache-2.0, `vendor/anthropic-sdk.LICENSE`)
